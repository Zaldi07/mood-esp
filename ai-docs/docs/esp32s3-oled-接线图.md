# 文档标题

## 文档说明

这份文档描述的是当前代码已经落地的硬件接线和功能映射。
重点同步到 2026-03-06 这版固件后的变化：

- 触摸 3 路全部已接入并有明确功能
- Astra 菜单已经启用二级菜单
- 已支持 `功德木鱼`、`打飞机`、`表情模式`、`时钟模式`
- 已支持 `DEBUG模式`
- 菜单内交互已调整为 `顶部单击 OK`、`顶部长按返回`

## 引脚总表

| 功能 | 外设引脚 | ESP32-S3 引脚 | 协议 | 说明 |
| --- | --- | --- | --- | --- |
| OLED CLK | CLK / SCL / SCK | GPIO13 | SPI | 时钟 |
| OLED MOSI | MOSI / SDA / DIN | GPIO12 | SPI | 数据 |
| OLED RST | RES / RST | GPIO11 | SPI | 复位 |
| OLED DC | DC | GPIO10 | SPI | 数据/命令选择 |
| OLED CS | CS | GPIO9 | SPI | 片选 |
| 触摸顶部 | 铜箔电极 | GPIO5 | Touch CH5 | 顶部长条触摸 |
| 触摸右上 | 铜箔电极 | GPIO7 | Touch CH7 | 右上区域触摸 |
| 触摸右下 | 铜箔电极 | GPIO6 | Touch CH6 | 右下区域触摸 |
| LIS3DH VCC | VCC | 3V3 | - | 传感器供电 |
| LIS3DH GND | GND | GND | - | 共地 |
| LIS3DH SDA | SDA | GPIO38 | I2C | 数据线 |
| LIS3DH SCL | SCL | GPIO37 | I2C | 时钟线 |
| LIS3DH INT1 | INT1 | GPIO36 | - | 中断输出，当前预留 |

## OLED

### 接线

| OLED 引脚 | ESP32-S3 引脚 |
| --- | --- |
| CLK / SCL / SCK | GPIO13 |
| MOSI / SDA / DIN | GPIO12 |
| RES / RST | GPIO11 |
| DC | GPIO10 |
| CS | GPIO9 |

### 当前配置

- 分辨率：`128x64`
- 接口：`SPI`
- SPI 频率：`10 MHz`
- 帧缓冲：`1024 bytes`
- 当前 UI 同时使用了：
  - 原始页缓冲绘制
  - `u8g2` 中文字体渲染

## 触摸布局

```text
┌─────────────────────┐
│      顶部 GPIO5      │
│                     │
│                     │   右上 GPIO7
│      OLED 屏幕      │
│                     │   右下 GPIO6
│                     │
└─────────────────────┘
```

### 触摸参数

- 按下阈值：`delta >= 300`
- 释放阈值：`delta <= 120`
- 去抖：`3` 次连续样本
- 有效点击时长：`40ms ~ 800ms`
- 最小点击间隔：`250ms`
- 双击窗口：`500ms`

### 当前交互映射

#### 主界面

- 顶部双击：进入 Astra 菜单
- 顶部单击：
  - 普通表情模式下切换表情
  - 时钟模式下忽略
  - 功德木鱼模式下敲木鱼
- 右侧滑动：切换 `表情模式 <-> 时钟模式`

#### Astra 菜单

- 顶部单击：`OK / 进入当前项`
- 顶部长按：返回 / 退出当前层
- 右上单击：上移
- 右下单击：下移
- `user_item` 页面：
  - 顶部单击仍然是 `OK`
  - 顶部长按作为统一返回动作

#### 功德木鱼模式

- 顶部单击：敲木鱼
- 顶部长按：返回菜单
- 屏幕右下角显示 `顶长返回` 作为提示

#### 打飞机模式

- 自动开火：约每 `200ms` 发射一次
- 右上长按：持续左移
- 右下长按：持续右移
- 上滑：快速左移一次
- 下滑：快速右移一次
- 左右晃动设备：使用 LIS3DH 左右倾斜控制飞机移动
- 顶部长按：退出打飞机

### 各项说明

  - 进入木鱼玩法界面
- `打飞机`
  - 进入 shooter mini-game
- `方向标定`
  - 调用 LIS3DH 引导标定流程

  - 切换主显示为表情动画或全屏时钟
- `DEBUG模式`
  - 打开后左上角显示方向调试叠加层
- `系统状态`
  - 显示模式、校时状态、Debug 开关、方向、内存、运行时间

## 显示模式

### 表情模式

- 主界面渲染表情动画
- 转向时自动切换左右转向表情
- 回中后恢复当前用户选择表情

### 时钟模式

- 主界面只显示大号时间
- 未完成校时时显示运行时长
- 屏幕下方状态文案会显示 `TIME` 或 `UP`

### DEBUG 模式

- 关闭时：左上角不显示方向字样
- 开启时：左上角显示方向叠加层，例如 `L N`

## LIS3DH

### 接线

| LIS3DH 引脚 | ESP32-S3 引脚 | 说明 |
| --- | --- | --- |
| VCC | 3V3 | 供电 |
| GND | GND | 共地 |
| SDA | GPIO38 | I2C 数据 |
| SCL | GPIO37 | I2C 时钟 |
| INT1 | GPIO36 | 当前预留 |

### 当前配置

- I2C 地址：`0x18`
- I2C 端口：`I2C_NUM_0`
- I2C 频率：`400 kHz`

### 当前用途

- 方向检测
- 引导标定
- 左右转向表情触发
- Debug 模式方向叠加显示
- 打飞机模式下的左右倾斜控制
