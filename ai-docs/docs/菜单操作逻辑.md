## 输入层语义

### 物理触摸区域

- `顶部`：`GPIO5 / Touch CH5`
- `右上`：`GPIO7 / Touch CH7`
- `右下`：`GPIO6 / Touch CH6`

### 触摸层输出事件

每次轮询会得到这些语义：

- `valid_click`
- `double_click`
- `click_count`
- `released`
- `press_ms`
- `gap_ms`
- `swipe`

当前 `double_click` 只用于：

- `顶部`

当前 `swipe` 支持两种：

- `TOUCH_SWIPE_UP`
- `TOUCH_SWIPE_DOWN`

## 状态机概览

应用层目前只有两个大状态：

- `APP_STATE_NORMAL`
- `APP_STATE_MENU`

但 `APP_STATE_NORMAL` 里又分成几个子场景：

- 普通表情模式
- 时钟模式
- 功德木鱼模式
- 打飞机模式

所以实际输入语义不是全局统一的，而是“随当前模式切换”。

## 统一导航规则

当前项目后续都按这套规则收敛：

- 主界面：`顶部双击` 进入菜单
- 菜单体系：`顶部单击 OK`、`顶部长按返回`、`右上/右下` 负责导航
- `功德木鱼` 保留特例：`右下单击` 进入菜单
- `打飞机` 使用 `顶部长按` 退出

页面提示文案也统一按这个口径：

- 返回上一层：写 `返回`
- 退出当前模式：写 `退出`
- 进入菜单：写 `菜单`

## 主界面逻辑

### 普通表情模式

- 顶部双击：进入 Astra 菜单
- 顶部单击：切换表情
- 右侧滑动：切换 `表情模式 <-> 时钟模式`

### 时钟模式

- 顶部双击：进入 Astra 菜单
- 顶部单击：忽略，不切表情
- 右侧滑动：切换 `时钟模式 <-> 表情模式`

### 功德木鱼模式

- 顶部单击：敲木鱼
- 右下单击：进入 Astra 菜单
- 顶部双击：不再用于进菜单，避免连续敲击误触

### 打飞机模式

- 顶部单击：发射
- 顶部长按：退出打飞机
- 右上单击或上滑：左移
- 右下单击或下滑：右移

## Astra 菜单逻辑

当前菜单逻辑已经和主界面分开。

### 进入菜单后

- 会先暂停主界面动画
- `astra_menu_open()` 打开 Astra-Lite 菜单
- 状态从 `APP_STATE_NORMAL` 切到 `APP_STATE_MENU`

### 菜单内键位语义

- 顶部单击：`OK / 进入当前项`
- 顶部长按：返回 / 退出当前层
- 右上单击：上移
- 右下单击：下移

当前返回阈值默认是 `500ms`。

这版的核心变化是：

- `OK` 和 `返回` 统一收口到顶部键
- `右上 / 右下` 只负责导航
- `右下单击` 现在立即下移，不再等待任何返回窗口

### user_item 页面

`系统状态` 这类页面属于 `user_item`。

在 `user_item` 内部：

- 顶部单击仍然是 `OK`
- 顶部长按作为统一返回动作
- 为了避免 `OK` 和返回打架，进入 `user_item` 后会清掉挂起的延迟输入状态

## 菜单动作结果

### 游戏选择 -> 功德木鱼

- 如果当前不在木鱼模式：进入木鱼模式
- 如果当前已在木鱼模式：退出木鱼模式并恢复普通表情

### 游戏选择 -> 打飞机

- 如果当前不在打飞机模式：进入打飞机
- 如果当前已在打飞机模式：退出打飞机并恢复普通表情

### 方向标定

- 关闭菜单
- 执行 LIS3DH 引导标定
- 标定结束后恢复主界面动画

### 显示模式

- `表情模式`：主界面显示表情动画
- `时钟模式`：主界面显示全屏时钟

### DEBUG模式

- 开启后左上角显示方向调试叠加层
- 关闭后左上角不显示方向字样

### 系统状态

- 进入只读状态页
- 当前显示内容包含：
  - 模式
  - 时间同步状态
  - 显示模式
  - Debug 开关
  - 方向
  - 内存
  - 运行时间

## 当前设计的优点

- 主界面和菜单态输入语义分离，避免全局混乱
- `OK` 和 `返回` 已不再共享顶部键
- 木鱼模式不再因为连续敲击误进菜单
- `右下单击下移` 已恢复立即响应，手感比“双击返回”方案更自然
- 菜单返回动作统一成 `顶部长按`，比“右下长按返回”更符合直觉

## 当前设计的代价

- 顶部键同时承担 `单击 OK` 和 `长按返回`
- 如果后面继续给顶部键叠更多菜单语义，仍然要控制复杂度

## 结论

截至 2026-03-06，当前正式逻辑可以概括成一句话：

- 主界面主要靠 `顶部双击进菜单`
- 菜单内部主要靠 `顶部单击 OK、顶部长按返回、右上上移、右下下移`
- 木鱼和打飞机模式各自对主界面输入做了单独重映射
