# 文档标题

## 文档目标

这份文档不再只讲“边充边用”，而是把你当前 `CarMood` 项目的现状和下一版 `CarMood Pro` 的硬件目标合在一起，形成一份可直接指导重新画原理图的总设计说明。

文档重点解决 4 个问题：

- 当前这版原理图已经做了什么
- `CarMood Pro` 要新增哪些能力
- 新版原理图应该按什么模块重画
- 哪些地方必须按 datasheet 和参考设计来，不要再靠猜

## 当前项目现状

从当前代码、已有文档和 `carmood_Schematic1_2026-03-07.tel` 来看，现有项目已经围绕下面这些能力展开：

- `ESP32-S3-WROOM-1-N8R8`
- 小尺寸 OLED 显示
- 触摸输入
- `LIS3DH` 姿态传感器
- `SHTC3` 温湿度传感器
- `PAM8302` 功放和喇叭
- `USB Type-C`
- 单节锂电池接口
- `TP4056` 充电
- `3.3V LDO`

当前原理图说明你已经完成了第一版系统拼装，方向并没有乱，问题主要集中在：

- 电源路径管理不完整
- 某些芯片模式脚和使能脚需要按具体料号修正
- 部分外设接法需要从“能连上”升级到“工程上更稳”

## CarMood Pro 的目标

`CarMood Pro` 不应该只是把现在这块板加几个器件，而是应该明确变成一个更完整的便携式交互设备。

建议新版目标定义如下：

### 核心能力

- 更大的屏幕
- 电池供电
- 支持 USB 充电
- 支持标准意义上的边充边用
- 主控继续基于 `ESP32-S3`

### 交互能力

- 扬声器播放
- 麦克风采集
- 后续支持语音交互
- 为 AEC 留出完整的音频链路

### 环境与姿态能力

- 温湿度检测
- 姿态检测
- 触摸输入

### 调试与扩展能力

- 保留 USB 下载/调试
- 保留测试点
- 为后续传感器、音频、屏幕升级留足接口和电源余量

## 当前版本到 Pro 版本的升级思路

建议把 `CarMood Pro` 看成是下面这条升级路线：

```text
CarMood v1
  -> 修正基础电源和外设接法
  -> 升级屏幕与电池供电方案
  -> 引入稳定的系统电源路径
  -> 再加入麦克风、音频前端和 AEC
  -> 形成 CarMood Pro
```

关键原则是：

**先把系统供电架构做对，再谈更大屏幕、音频和语音。**

## CarMood Pro 推荐的模块划分

新版原理图建议分成 8 个模块画，不要再全图混着连。

### 1. USB 输入与保护模块

包含：

- `USB Type-C`
- `VBUS`
- `D+ / D-`
- `CC1 / CC2`
- USB 输入滤波电容
- ESD/TVS 保护

职责：

- 提供 5V 输入
- 支持 USB 下载或 USB 通信
- 保护接口抗静电和插拔冲击

### 2. 充电与电源路径模块

这一块是 `CarMood Pro` 最重要的升级点。

目标不是简单“能充电”，而是：

- 插 USB 时系统能稳定运行
- 电池能被正确充电
- 拔 USB 时系统不断电

所以推荐结构是：

```text
USB_5V
  |
  v
带 power-path 的充电管理
  |                \
  |                 \-> BAT -> 单节锂电池
  v
VSYS / SYS_IN
```

这里的关键不是芯片名，而是功能：

- `BAT` 是电池节点
- `VSYS` 是系统供电节点
- 两者不能再像旧方案那样简单视为一根线

### 3. 系统 3.3V 稳压模块

`VSYS` 后面再生成系统 `3V3`。

推荐思路：

- 低风险版：`VSYS -> 3.3V LDO`
- 高效率版：`VSYS -> 3.3V Buck`

如果继续用 LDO，必须记住：

- `VIN` 接 `VSYS`
- `VOUT` 接 `3V3`
- `EN/CE` 必须按完整料号 datasheet 接
- 不要再按系列名猜

### 4. ESP32-S3 最小系统模块

这块建议单独画，先做到“独立可启动”：

- `3V3`
- `GND`
- `EN`
- `IO0`
- USB 或 UART 下载接口
- 去耦电容
- 测试点

要求：

- 不依赖屏幕
- 不依赖传感器
- 不依赖音频
- 只要上电正常就能烧录和打印日志

### 5. 显示模块

CarMood Pro 既然要更大屏幕，这一块不要再简单沿用旧 OLED 的思路，要先选清楚：

- 屏幕尺寸
- 接口类型
- 供电电压
- 是否自带驱动 IC
- 是否需要背光电源
- 是否是裸屏 FPC 连接

如果是裸屏排线，必须额外确认：

- `Pin 数`
- `Pitch`
- 接触面方向
- 推荐的 `FPC/FFC` 连接器

### 6. 传感器模块

当前已知有两类：

- `LIS3DH`
- `SHTC3`

这一块建议在 Pro 版统一成规范的传感器总线设计。

推荐：

- 如果地址不冲突，优先共用一条 `I2C`
- 每条 `I2C` 总线有且仅有一组合理的上拉
- 每个器件附近放自己的去耦电容

### 7. 音频输出模块

用于喇叭播放。

建议明确分成两部分：

- 音频源
- 功放 + 喇叭

如果继续沿用 `PAM8302`，要注意：

- 输入耦合
- 静音/使能脚
- 供电去耦
- 喇叭布线和地回流

### 8. 音频输入与 AEC 模块

既然你明确说 `CarMood Pro` 绝对需要：

- 麦克风
- AEC 芯片

那这就已经不是“加一个麦克风”这么简单了，而是完整音频前端。

至少要包含：

- 麦克风本体
- AEC / 音频前端芯片
- 播放参考信号输入
- 主控侧音频接口

因为 AEC 要工作，必须同时拿到两路信息：

- 麦克风实际拾取的声音
- 设备自己送去喇叭的参考音频

逻辑结构如下：

```text
主控播放流 -> AEC参考输入 -> 功放 -> 喇叭
麦克风 -> AEC处理 -> 主控录音流
```

## 为什么旧版 `TP4056` 不适合 Pro

旧版的思路更接近：

```text
USB_5V -> TP4056 -> BAT
BAT -> 开关 -> LDO -> ESP32
```

这个方案的优点是：

- 简单
- 便宜
- 能快速搭起来

但对 `CarMood Pro` 这种要上：

- 更大屏幕
- 喇叭
- 麦克风
- AEC
- Wi-Fi

的设备来说，问题会被放大：

- 系统负载和充电耦合
- 充电终止不准
- 音频和无线峰值电流容易搅乱电源
- 插 USB 时行为不够稳定

所以 `CarMood Pro` 推荐直接升级成带 `power path` 的结构，而不是继续围绕 `TP4056` 修补。

## CarMood Pro 推荐的总体电源路径

建议新版从电源视角按下面的逻辑来画：

```text
USB Type-C VBUS
  |
  +--> USB ESD/保护
  |
  +--> 带 power-path 的充电管理
           | \
           |  \-> BAT -> 锂电池
           |
           +-> VSYS
                 |
                 +-> 3.3V 主稳压
                        |
                        +-> ESP32-S3
                        +-> 传感器
                        +-> 显示
                        +-> 音频前端
                        +-> 功放
```

然后建议明确 4 个电源网络名称：

1. `USB_5V`
2. `BAT`
3. `VSYS`
4. `VCC_3V3`

这样原理图会清楚很多。

## CarMood Pro 的显示升级建议

因为你准备把屏幕做大，建议先决定下面 5 件事，再画屏幕模块：

1. 是 OLED 还是 LCD
2. 是 SPI、8080 并口、RGB 还是 MIPI
3. 是否需要背光驱动
4. 是否是模块屏还是裸屏 FPC
5. 分辨率和刷新需求是否超出 ESP32-S3 当前带宽预算

如果还是走简单稳定路线，建议优先：

- 选带驱动 IC 的现成模块屏
- 优先 SPI 或成熟并口方案
- 裸屏 FPC 作为后续升级项

## CarMood Pro 的传感器建议

### `LIS3DH`

如果继续用 `I2C`：

- `CS` 拉高
- `SA0` 设定地址
- `SCL / SDA` 加外部上拉
- `RES` 接地
- `Vdd`、`Vdd_IO` 都要供电

### `SHTC3`

如果走 `I2C`：

- 和 `LIS3DH` 共总线是可行的
- 前提是地址不冲突
- 总线上有一组上拉即可

## CarMood Pro 的音频建议

如果你要做完整语音方向，建议把音频链路单独当成一个子系统：

### 输出链路

- 主控音频输出
- AEC 参考支路
- 功放
- 喇叭

### 输入链路

- 麦克风
- 前端偏置或数字接口
- AEC 芯片
- 主控录音输入

### 原理图阶段必须确认的点

- 麦克风是模拟还是数字
- AEC 芯片输入输出接口是什么
- 主控和 AEC 之间是 `I2S`、`PDM`、`PCM` 还是别的总线
- 是否需要额外时钟
- 参考音频怎么送进 AEC

## CarMood Pro 建议的重画顺序

明天重新画时，建议严格按下面顺序来：

1. 先画 `USB + 充电 + power-path`
2. 再画 `3.3V 稳压`
3. 再画 `ESP32-S3 最小系统`
4. 再画 `下载 / 调试 / 测试点`
5. 再画 `显示模块`
6. 再画 `LIS3DH / SHTC3 / 触摸`
7. 最后画 `功放 + 麦克风 + AEC`

不要反过来先画音频和传感器，因为电源不定下来，后面全都不稳。

## 明天重画时每个模块都要自查什么

每画完一个模块，都强制检查下面这些问题：

### 通用检查

1. 供电脚是否全部接对
2. 去耦电容是否齐
3. 模式脚是否按 datasheet 接
4. 使能脚是否按具体料号接
5. 未使用脚是否按手册处理
6. 网络命名是否清楚

### 总线检查

1. `I2C` 是否有上拉
2. 地址是否冲突
3. `SPI` 的 `CS/DC/RST` 是否完整
4. USB 的 `CC1/CC2` 是否正确

### 电源检查

1. `USB_5V`
2. `BAT`
3. `VSYS`
4. `VCC_3V3`

这 4 条电源网必须逻辑清晰，不能混。

## 明天先追求什么

不要一上来就追求“终极 Pro 完整版”，建议分两步：

### 第一步：先画对基础版 Pro 主架构

先只保证：

- USB 输入正确
- 边充边用电源路径正确
- 3.3V 正确
- ESP32-S3 可启动
- 大屏接口逻辑清楚
- 传感器总线逻辑清楚

### 第二步：再叠加音频链路

等主系统稳了，再把：

- 麦克风
- AEC
- 功放
- 喇叭

完整接上去。
