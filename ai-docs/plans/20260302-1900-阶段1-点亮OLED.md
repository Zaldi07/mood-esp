## 描述

使用 ESP-IDF v5.5.2 内置的 `esp_lcd` 组件驱动 SSD1306 SPI OLED（128x64），验证硬件连接正确。

## 技术方案

- 使用 `esp_lcd_panel_ssd1306` 原生驱动，不手写 SPI 底层
- API 调用链：`spi_bus_initialize` → `esp_lcd_new_panel_io_spi` → `esp_lcd_new_panel_ssd1306` → `esp_lcd_panel_draw_bitmap`
- 内部维护 1024 字节帧缓冲（128x64/8）

## 引脚分配

| 信号 | GPIO |
| --- | --- |
| SCK | GPIO12 |
| MOSI | GPIO11 |
| CS | GPIO10 |
| DC | GPIO9 |
| RST | GPIO8 |
