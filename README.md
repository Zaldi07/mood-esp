1. 项目概述
项目名称
桌宠表情交互小屏（ESP32-S3 + 单色 OLED）
目标
做一个可电池供电的小设备，核心使用场景是桌面桌宠，强调“陪伴感、状态感、轻交互、低功耗”。当前核心体验是：
- OLED 显示像素风/机器人表情（动态）
- 通过人格系统自动切换表情 / 情绪
- 触摸进行模式切换、菜单操作和小游戏交互
- 根据设备运动状态显示方向/动态提示（不再作为主表情驱动）
- 播放简单音效（可选）
- 显示时间、电量
- 低功耗：静止后休眠，触摸/运动唤醒
当前实现方向更接近“可放在桌面长期运行的小桌宠”，而不是车内仪表类配件。

2. 硬件选型与物料清单（BOM）
核心板卡
- ESP32-S3 SuperMini（你这块：单核 160MHz、约 400KB SRAM、4MB Flash、无 PSRAM）
  - 足够支撑：单色 OLED + LVGL/轻量 UI + 传感器 + 简单音效
  - 不建议在这块板上做：大彩屏、多媒体、语音识别、MP3 解码等重任务
显示
- SPI OLED 单色屏（7P）
常见驱动：SSD1306/SH1106（分辨率通常 128×64 或 128×128）
  - 单色不影响核心功能，反而更省电、资源占用更小
运动传感器
- LIS3DH 三轴加速度计（I2C）
  - 可实现：静止/运动、晃动、敲击、倾斜/方向趋势检测
触摸
- 铜箔胶带（0.06mm，10mm 宽）：做触摸电极（3 区）
- 串联电阻 1kΩ（每根触摸线串一个，抗干扰/防尖峰）
结构与装配
- 3D 打印外壳（PLA）
- 螺丝套装：建议 M2×6/8/10 + M2 铜柱 + M3×8（喇叭）
- 28AWG 细软线、热缩管、绝缘胶带
- 万用表、砂纸（400/800/1200）
