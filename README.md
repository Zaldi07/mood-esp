1. 项目概述
项目名称
CarMood – 桌宠表情交互小屏（ESP32-S3 + 单色 OLED）
目标
做一个可电池供电的小设备，核心使用场景是桌面桌宠，强调“陪伴感、状态感、轻交互、低功耗”。当前核心体验是：
- OLED 显示像素风/机器人表情（动态）
- 通过人格系统自动切换表情 / 情绪
- 触摸进行模式切换、菜单操作和小游戏交互
- 根据设备运动状态显示方向/动态提示（不再作为主表情驱动）
- 播放简单音效（可选）
- 显示时间、电量
- 低功耗：静止后休眠，触摸/运动唤醒
当前实现方向更接近“可放在桌面长期运行的小桌宠”，而不是车内仪表类配件。

2. 硬件选型与物料清单（BOM）
核心板卡
- ESP32-S3 SuperMini（你这块：单核 160MHz、约 400KB SRAM、4MB Flash、无 PSRAM）
  - 足够支撑：单色 OLED + LVGL/轻量 UI + 传感器 + 简单音效
  - 不建议在这块板上做：大彩屏、多媒体、语音识别、MP3 解码等重任务
显示
- SPI OLED 单色屏（7P）
常见驱动：SSD1306/SH1106（分辨率通常 128×64 或 128×128）
  - 单色不影响核心功能，反而更省电、资源占用更小
运动传感器
- LIS3DH 三轴加速度计（I2C）
  - 可实现：静止/运动、晃动、敲击、倾斜/方向趋势检测
音频（可选）
- PAM8302 单声道功放（推荐）
- 8Ω 1W 小喇叭
- 音频输入可先用 PWM（提示音），后续再升级 I2S 方案
电源与充电
- 锂电池 3.7V（你选 503048/602040 这类 500~800mAh）
- TP4056 充电/保护模块（你买的可能不带插座，焊盘 B+/B-/OUT+/OUT-）
- 滑动开关SS12D07VG4 087（3脚2档，SPDT）：作为整机电源开关
- 470uF 电解电容（10V）：电源稳定必备
- 0.1uF（104）去耦电容：每个模块电源旁建议并 1 颗
- 10uF 电容（可选）：进一步稳 3V3
触摸
- 铜箔胶带（0.06mm，10mm 宽）：做触摸电极（3 区）
- 串联电阻 1kΩ（每根触摸线串一个，抗干扰/防尖峰）
电量检测
- 分压电阻：200k + 100k（或 1M+100k 也可）
- 0.1uF：ADC 中点滤波
结构与装配
- 3D 打印外壳（PLA）
- 螺丝套装：建议 M2×6/8/10 + M2 铜柱 + M3×8（喇叭）
- 28AWG 细软线、热缩管、绝缘胶带
- 万用表、砂纸（400/800/1200）

3. 电源拓扑（最终推荐接法）
你的系统里有功放、触摸、传感器。按你当前硬件，推荐不使用升压模块。
3.1 供电主链路
电池 → TP4056（充电+保护） → 开关 → SYS_3V3（或板载 3V3 电源网）→ OLED / LIS3DH / PAM8302
具体连线
- 电池 BAT+/- → TP4056 B+ / B-
- TP4056 OUT+ → 开关 COM（中间脚）
- 开关 ON 脚（拨到开机时与 COM 导通的那一脚）→ 系统电源正端
- TP4056 OUT- → GND
开关接法补充（避免接错）
- 3脚2档开关通常是 SPDT：中间脚是 COM，左右两脚是两个档位端。
- 本项目只用到“断电/上电”两种状态：接 COM + 任意一侧脚即可，另一侧脚悬空。
- 如何判断 ON 脚：
  1) 用万用表蜂鸣档测中间脚与侧脚导通关系；
  2) 拨到你希望的“开机方向”时，与中间脚导通的那一侧就是 ON 脚；
  3) 该脚接系统电源正端，另一侧不接线。
  4) 若开关方向和你预期相反，交换两侧脚即可（不影响安全）。
电容（非常重要）
- 系统电源正端与 GND：470uF（靠近功放供电点）
- ESP32 3V3 与 GND：0.1uF（靠近 OLED/LIS3DH 供电点）

4. 推荐引脚分配（你可以直接用）
原则：SPI OLED 用一组连续 GPIO，I2C 独立一组，音频/ADC/触摸互不冲突。
4.1 OLED（SPI 7P）
- SCK → GPIO12
- MOSI → GPIO11
- CS → GPIO10
- DC → GPIO9
- RST → GPIO8
- VCC → 3V3（建议）
- GND → GND
4.2 LIS3DH（I2C）
- SDA → GPIO38
- SCL → GPIO37
- INT1（可选）→ GPIO36
- VCC → 3V3
- GND → GND
- 上拉（若模块无）：SDA/SCL 各 4.7k 到 3V3
4.3 音频（PAM8302，PWM 提示音）
- PWM 输出 → GPIO4 → 串 1k → 功放 AIN
- 功放 VCC → 3V3
- 功放 GND → GND
- 喇叭接 SPK+/-
4.4 电池电量检测（ADC）
- BAT+ → 200k → VBAT_SENSE → 100k → GND
- VBAT_SENSE → ESP32 某个 ADC 引脚（以你板子标注 ADC 的 GPIO 为准）
- VBAT_SENSE 并 0.1uF 到 GND
4.5 触摸三分区
```
        ┌─────────────────────┐
        │    [GPIO5 顶部]      │  ← 菜单 / 确认 / 长按返回
        │                     │
        │                     │  [GPIO7 右上] ← 上/左
        │      OLED 屏幕      │
        │                     │  [GPIO6 右下] ← 下/右
        │                     │
        └─────────────────────┘
```
- 顶部电极 → 串 1kΩ → GPIO5 (Touch CH5)：菜单确认 / 顶部长按 / 模式内主操作
- 右上电极 → 串 1kΩ → GPIO7 (Touch CH7)：上移 / 左移 / 菜单向上
- 右下电极 → 串 1kΩ → GPIO6 (Touch CH6)：下移 / 右移 / 菜单向下

5. 功能规划（你最终要实现什么）
5.1 UI/动画
- 单色表情帧动画（眨眼、嘴巴开合、眼球移动）
- 状态机管理（Idle / Active / Turn / Shake / Sleep）
- UI 叠加信息：电量 + 时间（可选显示）
5.2 运动逻辑（桌宠）
- 静止判定：加速度波动小于阈值 N 秒 → 进入待机/睡眠
- 运动判定：加速度 RMS 超阈值 → 更新方向提示、动态输入或小游戏输入
- 左右倾斜趋势：横向轴加速度持续超过阈值时用于方向 overlay 或游戏控制
- “晃动/敲击”可作为后续扩展事件输入，但不再直接作为主表情来源
5.3 触摸交互
- 三键：菜单确认 / 上下切换 / 模式切换 / 小游戏操作
- 长按：返回、退出小游戏、进入特定功能
- 表情不再依赖手动点击切换，主要由人格 idle 自动驱动
- 去抖与阈值自校准（上电读取基线）
5.4 时间系统
- 省电优先：默认不常开 WiFi
- 开机/每天一次：WiFi 连上 NTP 对时，随后立即关闭 WiFi
- 离线走时：用 ESP32 RTC 计时，靠 NTP 校准漂移
5.5 电量显示
- 读取 VBAT 真实电压（从电池端分压）
- 映射到粗略百分比（3.3V~4.2V 区间），并做滤波
- 低电量提示：<3.5V 降低亮度/限制音效/进入省电
5.6 低功耗
- 静止 X 分钟进入深睡
- 唤醒源：LIS3DH 中断（或定时唤醒 + 检测）/ 触摸唤醒（视 S3 支持情况）
- 唤醒后恢复表情状态

6. 开发/装配步骤（强烈建议按顺序）
阶段 1：只点亮 OLED（不接功放）
- ESP32 用 USB 供电
- 接 OLED，跑最小例程（先不用 LVGL，先用驱动库）
- 验收：能画点/刷屏/显示一张表情
阶段 2：加入 LIS3DH
- I2C 扫描确认地址（0x18/0x19 常见）
- 打印加速度数据，确认三轴方向
- 验收：摇动数值明显变化，静止稳定
阶段 3：加入触摸
- 先打印 touch 原始值，做阈值
- 加串联电阻 330Ω，走线短并远离噪声
- 验收：三键稳定触发，误触率低
阶段 4：加入功放/喇叭（仍然 USB 供电）
- 先小音量 PWM 提示音
- 验收：不重启、不花屏、音效正常
阶段 5：加入电池系统（TP4056 + 开关 + 470uF）
- 先空载测量系统电源端电压，确认接线与开关方向正确
- 再接入主板电源输入
- 验收：电池供电稳定，功放响时不掉压重启
阶段 6：装壳（固定）
- 第一版：少打热熔胶，多用螺丝/铜柱/泡棉胶
- 热熔胶只点胶固定，不要浇死模块（后期要拆）
- 触摸区壳厚尽量 ≤1.2mm，电极与电池保持距离

7. 常见坑（你提前避掉就省很多时间）
1. 功放瞬态电流导致花屏/重启/触摸乱跳
  - 470uF 必加，触摸线远离喇叭线与功放输入线
2. TP4056 边充边用不稳定
  - 原型可以先接受；后续真要“插着电一直玩”，再升级电源路径管理
3. 触摸电极太小/太近导致串扰
  - 三段独立电极 + 间隔 ≥4mm + 串 330Ω
4. LVGL 配置过大导致内存爆
  - 单色 OLED 不需要大 buffer；别上来就开大分辨率 buffer
5. 电量读数跳动
  - ADC 中点并 0.1uF，采样多次取平均；播放音效时可暂缓更新

8. 交付验收标准（你开工就按这个验收）
- 上电 3 秒内显示默认表情
- 触摸三键稳定（误触率低）
- 人格切换后，表情风格和触发频率有明显差异
- 运动输入可正确更新方向提示或小游戏输入，不强制改主表情
- 时间显示正常（可 NTP 校时）
- 电量显示可用（随电压变化合理）
- 音效播放时不重启、不花屏（有 470uF 的前提）
- 静止进入待机/睡眠，运动/触摸可唤醒
